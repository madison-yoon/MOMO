# MOMO RAG 1~3차시 작업 계획

목표: 사용자 최종 작업지시서에 따라 메모리 StubEngine과 커밋 후 리뷰 색인만 적용한다.
설계: Python 기본 6개 파일, Spring 단일 RagClient와 ReviewService의 afterCommit 연결. DB·JWT·OAuth·React는 변경하지 않는다.

1. Python 테스트 작성 및 실패 확인: 청킹, 교체, 삭제, 관련도, 영화별 허용 ID, lifespan·서비스 토큰.
2. Python 기본 파일 구현, 전용 venv에서 패키지 설치·테스트.
3. Spring 테스트 작성 및 실패 확인: 커밋/롤백/동기화 없음, 실제 HTTP 계약·인증·타임아웃·장애 격리.
4. RagClient 구현 및 ReviewService 최소 연결, 기존 리뷰 회귀·빌드 확인.
5. 별도 H2 실행 프로필에서 두 서버 통신 확인. 공유 MySQL·기존 리뷰는 사용하지 않는다.
6. 실행·테스트 데이터 재현/정리·한계를 MOMO-RAG/README.md에 기록. Commit/Push 없음.

색인 실패 자동 복구·초기 전체 색인·회원 탈퇴 일괄삭제 연동·LangGraph·LLM·React UI는 제외한다.
