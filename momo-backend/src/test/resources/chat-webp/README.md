# WebP validation fixtures

Copied unchanged from the TwelveMonkeys ImageIO 3.15.3 test resources:
https://github.com/haraldk/TwelveMonkeys/tree/twelvemonkeys-3.15.3/imageio/imageio-webp/src/test/resources/webp

The upstream BSD-3-Clause license is preserved in LICENSE-TwelveMonkeys.txt.

- small_1x1.webp: small VP8 fixture, also used to construct two-frame test animations.
- blue_tile.webp: VP8 fixture used to test aggregate animation pixel limits.
- lossless.transparent.webp: extended WebP with alpha.
- 2_webp_ll.webp: VP8L lossless fixture.

Malformed and oversized containers are generated by the tests. No production or
user-uploaded images are included. Do not replace these fixtures with user data.
